Install, update or delete skills

Choose a management action below. These commands install or manage the five skills for your selected harness.

Install skills

Run after workspace creation from its root. This installs all five skills for your selected harness.

node skills.js --codex

Codex: $d-documents, $d-frontend, $d-backend, $d-testing, $d-manual.

List available coding agents with node skills.js --list-harnesses. Read the skill guide ↗

Update skills

Updates all five managed skills from the latest GitHub version. Requires Git and network access.

Delete skills

This command deletes all five managed skills and their managed wrappers for the selected harness.

Copy a skill command

Use these commands to run a workflow skill in your agent. This is separate from installing, updating or deleting skills.

Open your agent in the module workspace, then copy the command for your current phase.

Use d-documents for Phase 1 documents, d-frontend for each Phase 2 prototype, and d-backend for Phase 3 implementation and integration. Use d-testing for scoped verification and d-manual to prepare handover docs from verified behavior. These five skills install together by default.

Optional: enter your module code to include it and its mockup path in prompts 1 and 2 only. It must match module.config.json; the agent verifies the actual folder.
